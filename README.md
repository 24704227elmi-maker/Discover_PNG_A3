## 1. Project Overview

Discover PNG is a responsive tourism information website that introduces users to Papua New Guinea's destinations, culture and travel experiences. It is designed for local travellers, international visitors and students interested in exploring Papua New Guinea.

## 2. Website Pages

The website contains three connected pages:

- **Home (`index.html`):** Introduces Discover PNG and its purpose.
- **Destinations & Culture (`destinations.html`):** Presents destinations and category filters for All, Nature, Culture and Cities.
- **Plan Your Visit (`contact.html`):** Provides a travel enquiry form for visitors to enter their details and travel preferences.

## 3. Technologies Used

- HTML5 for page structure and semantic content.
- CSS3 for styling, Flexbox, CSS Grid and responsive layouts.
- JavaScript for interactive destination filters and enquiry form validation and feedback.
- Git and GitHub for source-code management.
- GitHub Pages for online publication.

## 4. Main Features

- Multi-page website with connected navigation.
- Destination cards with category filtering.
- Responsive layout for mobile, tablet and desktop screens.
- Travel enquiry form with required-field validation and submission feedback.
- Accessible labels, alternative text and visible keyboard focus styling.

**Note:** The enquiry form is a demonstration. It does not transmit or store personal information.
