# Discover PNG — Assessment 3

Responsive HTML5 + CSS3 website for ISO229 Web Design.

## Project
Discover PNG is a small tourism and cultural information website about Papua New Guinea. It contains:
- Home
- Destinations & Culture
- Plan Your Visit / Travel Enquiry

## Assessment 3 improvements
- Organised external CSS3 stylesheet
- CSS variables for colours, spacing and reusable design values
- Flexbox for navigation and form choice groups
- CSS Grid for feature and destination card layouts
- Responsive mobile, tablet and desktop breakpoints
- Responsive images using flexible sizing and aspect-ratio
- Consistent buttons, cards, forms and spacing
- Visible keyboard focus states
- Readable colour contrast and semantic HTML structure

## Technologies
HTML5, CSS3, Flexbox, CSS Grid, media queries, Git and GitHub Pages.

## Responsive testing
Test at approximately:
- Mobile: 320–480px
- Tablet: 600–900px
- Desktop: 1024px and wider
